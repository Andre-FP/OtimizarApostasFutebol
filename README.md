# Data Analysis for Soccer

Simple analysis in soccer statistics aiming to encounter the best value to bet consistently on soccer betting sites, to win in the long run.
Example: Find the best value to consistently bet for the number of gols or corners that will happen in matches.

## Conclusion:

Usually, there isn't a single value that can be consistently used for soccer bets, even considering the same team or the same confrontation of teams.
It happens because the betting websites already take these probabilities into account to calculate the odds of the bet. So, if you bet every time on a single value,
the website will win in the long run, unless the odds are badly calculated, which happens when a team surprises by its performance, playing much better or much worse than in fewer games before.

This conclusion was achieved by comparing the probability of each value with the odds at the time of developing this analysis. At that time, the odds suited exactly the trend of probabilities of these datasets,
but in a way that benefited the casino.
