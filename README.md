# Data Analysis for Soccer

Simple analysis in soccer statistics aiming to encounter the best value to bet consistently in soccer bet sites, to win in the long run.
Example: Find the best value to consistently bet for the number of gols or corners that will happen in matches.

## Conclusion:

Usually, there isn't a single value that can be consistently used for soccer bets, even considering the same team or the same confrontation of teams. 
It happens because the bet websites already takes these probabilities into account to calculate the odd of the bet. So, if you bet everytime a single value, 
the website will win in the long run, unless the odds are badly calculated, that happens when a team surprise by its performance playing much better or much worse than fewer games before.

This conclusion was achieved comparing the probability of each value with the odd in the time of developing this analisys. In that time, the odd suited exactly the trend of probabilites of these datasets,
but in a way for benefits of the cassino.
